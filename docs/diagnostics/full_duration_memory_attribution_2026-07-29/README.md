# Full-Duration Memory Attribution

Date: 2026-07-29

Status: diagnostic checkpoint complete. This is one production-shaped
attribution trial, not a storage-profile, cache-policy, or long-run memory
promotion result.

## Scope

The run used the full 1,188,000-frame Sleepyfish hybrid archive through the
mounted Johnson Lab volume, the production 64 MiB TensorStore cache, four
shared workers with one current-frame reservation, and the byte-budgeted
resident canonical-detection strategy. The process sampled current and
lifetime-peak RSS every 25 ms. Repository snapshots report exact lower bounds
for memory whose owning containers expose their allocations; they do not claim
to account for all process RSS.

Crimson implementation commit:

`1ba2ba391d5159ed2a6cbcab8aaed0c369cb25f8`

The benchmark reported `crimson_worktree_dirty=false`.

The trial passed correctness, current-frame reservation, stale-publication,
traversal, and shutdown checks. The scheduler recorded no work exceptions.

## Attribution

The largest reported owners before shutdown were:

| Owner | Retained lower bound |
| --- | ---: |
| Crop geometry rows and frame index | 199.9 MiB |
| Subject-shape placement/index/cache | 139.6 MiB |
| Eye-geometry placement/index/cache | 128.7 MiB |
| Motion preload | 42.4 MiB |
| Canonical-detection resident UI columns | 27.2 MiB |
| Tail-kinematics preload | 26.8 MiB |
| Eye-angle preload | 18.1 MiB |
| Subject-mask retained data and caches | 31.0 MiB total |
| Keypoint frame offsets | 9.1 MiB |
| Canonical-detection frame offsets | 9.1 MiB |

The three geometry repositories alone account for about 468 MiB. This is the
main actionable result: most explicitly retained memory is in million-row
placement, geometry, and per-frame index structures, not the bounded current
frame or detection presentation caches.

The approximately 1.16 GiB attribution gap at the readiness peak cannot be
assigned to a product from RSS alone. It includes TensorStore handles and
internal caches, active decode/read allocations, allocator overhead and
retention, libraries, and thread stacks. The timeline shows that much of this
peak is transient: current RSS fell by roughly 800 MiB before the first
presentation snapshot, while the repositories remained alive. Releasing all
repositories reduced RSS from 1,062.8 MiB to 343.6 MiB.

## Decision

Do not enlarge caches or reject the resident-detection strategy based on this
peak. Detection residency is 27.2 MiB and the detection page cache is only
0.2 MiB at shutdown. The next memory work should target eager full-duration
geometry placement/index representations:

1. Preserve the current bounded caches and scheduler reservation policy.
2. Replace crop geometry's eager row vector and per-frame hash map with an
   offset-indexed, pageable repository where the persisted contract permits it.
3. Evaluate the same compact frame-index policy for subject-shape and
   eye-geometry placement metadata without changing coordinate semantics.
4. Add TensorStore/allocator attribution only after the application-owned
   geometry owners are reduced; the current lower bound is already sufficient
   to rank that work.
5. Run a longer sequential/random-seek trial after those changes to establish
   a bounded steady-state curve. This single run does not establish a memory
   leak or a thermal gate.
